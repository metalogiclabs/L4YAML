## The missing distinction

`SequenceValues.nested` closes the enclosing sequence tail with nil when it
returns a flat marked-column family. Existing per-owner framed routes retain
that collection for one value line at a time. The joint continuation retains
the intervening collection and all marked-entry choices in one context.

`Joint` reads each real frame's kind. A marked mapping layer is an `EntryStep`
with both omitted-value and explicit-value arms; an unmarked mapping or
sequence layer retains its arbitrary sibling tail. `Context` uses precisely
the nonnegative levels projected from `sc.indents`, in stack order. There is
no stored independent list, source position, scanner flag or ghost index.
Helper lemmas quantify over existing frame lists while proving the algebra;
the state invariant itself has no additional frame index.

The algebra proves:

- closing and popping frames, restriction to surviving marks, and mapping the
  result predicate;
- consuming a real colon/value at a marked mapping while retaining its tail;
- resuming an actual sequence layer with a non-nil sibling;
- pushing compact sequences and questions from their full input slots;
- projecting to the previous `EntryValues` and `NodeValues` interfaces.

Projection requires ordered actual levels and coverage of the marked mapping
slots. Order is derived universally from `IndentStackMono.Mono`. Existing
`PendingKeySound.SlotsOk` states size and nonnegative-column facts; it does
**not itself state that marked levels are mappings**. This remains explicit
as `MarkedMaps` in the generic projection. Finite kernel checks supply it for
the initialized examples. Universal preservation of that condition and the
new semantic context has not been claimed from the existing invariant.

## Why the flat family cannot be silently lifted

`Separation.lean` uses the initialized scanner for `- a\n- b\n` and its real
non-nil grammar sibling. With the result predicate `P e := e = afterA`, the
flat family holds at `afterA` because there are no marked columns. A joint
context would consume the sibling and force `afterB = afterA`, a contradiction.
Thus a reconstruction uniformly in the result predicate is formally refuted.

This is a result-parametric separation of representations. It is **not** a
refutation for the particular predicate `SLYamlStream start`, a counterexample
to an accepted production theorem, or proof that every alternative invariant
is impossible. It explains why preserving the original context is necessary
for this general continuation construction.
