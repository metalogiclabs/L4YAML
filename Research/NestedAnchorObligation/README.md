## Adopted selection criterion

Select completion work by the **existing obligation it removes**. Before extending
a proof, name the owner field/consumer, its capstone chain, the predicted directed
dashboard change, and the cheapest falsifier. Promotion requires verified proof
and a remeasured dependency or directed-census improvement on the exact changed
tree. New lemmas, native cases, an informative fragment theorem, or an increased
population count do not by themselves discharge a completion obligation.

Keep production PR qualification separate. Preserve useful bounded evidence and
negative results even when a proposed completion contribution is rejected.

## Executed experiment

actual payload through nested mapping frames and dedentation. Candidate chain:
registry/source-event correspondence -> universal `scan_trace` -> corrected
Blueprint 7.7 `parse_iff_grammar`. The last two obligations remain open.

`YamlValue` trees. It starts each positive scanner execution at `ScannerState.mk'`
and executes actual transitions. It checks every successful preprocessing step,
counts actual popped frames, then intervenes at the reached alias state.

## Executed follow-up: pay the existing root producer

The target is `PendingNode.pendingBlock[10].h_kslot` on the capstone path:
`accum_block_pending` -> `accum_step_block` -> the existing scanner accumulation
fold -> `scan_strict_proof` / `parse_strict_proof`.

After a successful unmodified `StreamAccum.lean` elaboration, the probe removed
only this constructor field's `∨ PackAlt sc`. Elaboration failed, as retained in
`Evidence/keyslot-strengthening.txt`. The two earliest errors are mechanical
disjunction destructuring changes. The first producer failure is the root `-`
in `accum_block_on_noPending` (source line 27037): it supplies
`PackAlt.step_blockEntry ... (PackAlt.ofRefused ...)` where the strengthened
field requires the informative continuation for every actual marked column.

This is a **PRICED first-round lower bound**, not a fixpoint, a refutation of the
stronger statement, or a completed repair. The probe added no admissions and
generated no replacement `.olean`. The original source was restored byte for
byte, SHA-256 `3e7761d4fbaee92379326092ac2f4396c30294546a3875ddb766b12c97c08cdb`,
then elaborated successfully again. The owner's source file is byte-identical.

The first missing producer payment is implemented in `root-keyslot-payment.patch`.
On the exact owner checkout, apply it with `git apply --unidiff-zero`.
Its caller already carries `PendingKeySound.Sound`; the patch forwards that
existing invariant to `accum_block_on_noPending`. Together with the root's dead
explicit-key register, existing lemmas derive `MarkedColsIn sc []`, transport it
through actual preprocessing and `-` dispatch, and supply the informative
`h_kslot` field. No new library lemma, carrier, scanner field, runtime change or
ghost index is added.

This is an empty **actual state projection**, not an assumed grammar route or a
replacement `True` escape. There are no explicit-key slots to discharge in this
root case. The actual producer now writes `Or.inl`, and the existing consuming
capstones reach that proof. The old `Or.inr (PackAlt.step_blockEntry ...)` supply
is removed. The six other supplies of this field remain split cases.

Before the proof change, `RootProducerControls.lean` passed 42 executions from
real initialization: empty/singleton/nested sequences, nested explicit keys,
anchors/aliases, LF/CRLF, comments and BOM. Both intermediate and resulting
